# 外国文学翻译质量准则

## 定位

馆内译文以“准确、完整、自然、适合朗读”为先，不把未经审校的机器初译标为精品译文。

## 质量等级

- C：可理解的机器初译，可能有直译、漏译、英文残留或排版问题，不得作为正式定稿。
- B：经过模型逐句审校，内容完整、术语基本统一，可供馆内试读。
- A：通过术语核对、静态门禁和人工抽检，达到正式听读发布标准。

## 标准流程

1. 从已确认的公版来源取得原文，只在完整句子或段落处结束。
2. 使用 `qwen3:8b` 生成逐段初译。
3. 使用 `qwen3:14b` 对照原文逐句审校，不仅润色中文。
4. 应用 `content/translation-glossary.json` 中的统一译名。
5. 执行 `npm run translation:audit`，检查截断、段落、排版、英文残留和引号。
6. 对抽检作品人工核对事实、专名、语气和朗读自然度。
7. 运行内容校验、导入及 lint/test/build 后发布。

批量审校必须通过 `--ids=` 小批次执行；脚本会在 `storage/translation-backups/` 保存修改前版本。
